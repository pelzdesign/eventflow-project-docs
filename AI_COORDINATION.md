# AI-координация EventFlow — единая точка входа

**Назначение:** единая навигация по рабочей переписке AI-помощников EventFlow и связанным техническим вопросам. Этот документ не дублирует полные обсуждения: он указывает, где находится каноничная переписка, к какому направлению она относится и где фиксируются итоговые решения.

## Правила ведения переписки

1. Переписка остаётся в соответствующем GitHub Issue; пользователь не переносит сообщения между помощниками.
2. В Issue #2 используются метки `QUESTION FOR MAIN`, `ANSWER FROM MAIN`, `STATUS UPDATE`, `USER DECISION REQUIRED`.
3. В Issue #1 фиксируются общие решения EventFlow и передача контекста между помощниками.
4. Значимые итоговые решения переносятся из переписки в канонические документы проекта. Комментарий в Issue — история обсуждения и координации, а не замена спецификации или журнала решений.
5. Если вопрос затрагивает несколько репозиториев, в ответе указываются конкретные файлы, ветки, PR и ссылки; не создавать дублирующие копии документов без необходимости.
6. GitHub Issues — асинхронный канал. Комментарий не запускает завершившийся сеанс другого помощника и не гарантирует мгновенный ответ.

## Текущий фокус

### Новогоднее приглашение — главный визуальный приоритет

Основная текущая задача — вернуться к анализу визуальных референсов новогоднего приглашения. Сценарий уже согласован и зафиксирован в центральной медиатеке:

[NEW_YEAR_STORY_SCENARIO.md](https://github.com/pelzdesign/eventflow-media/blob/main/references/products/new-year/fairytale/NEW_YEAR_STORY_SCENARIO.md).

Пользователь подобрал дополнительные референсы, но пока не загрузил их в папку `references/products/new-year/fairytale/` репозитория [eventflow-media](https://github.com/pelzdesign/eventflow-media). До загрузки новых материалов не следует утверждать, что они просмотрены или анализировать их по одним названиям. После загрузки помощник проверяет фактическое содержимое, изучает изображения, связывает наблюдения с исходными файлами и готовит анализ/раскадровку в рамках уже согласованного сценария.

### Проверенный способ анализа групп референсов

В Issue #2 от 16 ноября 2026 года помощник модуля сертификатов сообщил об успешном эксперименте: GitHub Actions сформировал контактный лист из изображений медиатеки, результат был передан через GitHub Connector в визуальный контекст модели; временный Base64-переносчик после анализа удалён. Эксперимент подтверждает принципиальную работоспособность подхода, но не автоматически доказывает поддержку любых форматов, размеров и объёмов.

[Исходный комментарий с описанием эксперимента и запросом на документацию](https://github.com/pelzdesign/eventflow-certificates/issues/2#issuecomment-6914811091).

Этот workflow следует документировать как повторно используемый технический процесс, с явным разделением подтверждённых возможностей и ограничений. Он является инструментом для основной задачи анализа новогодних референсов, а не заменой самой задачи.
