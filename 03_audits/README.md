# Технические аудиты EventFlow

Здесь хранятся результаты проверок системы:

- структура базы данных;
- безопасность и RLS-политики;
- RSVP и обработка ответов гостей;
- серверные функции;
- приложение и пользовательские сценарии.

Каждый аудит должен содержать дату, область проверки,
обнаруженные проблемы, выводы и рекомендации.
