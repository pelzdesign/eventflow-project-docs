# Проектные решения EventFlow

## Статусы

- **Согласовано** — решение принято и должно учитываться в дальнейшей работе.
- **Предварительно согласовано** — направление определено, отдельные детали ещё требуют уточнения.
- **Открытый вопрос** — решение не принято.
- **Изменено** — ранее принятое решение заменено новым.

Каждая запись должна содержать дату, тему, контекст, принятое решение и статус. В журнал включаются только решения, подтверждённые в ходе обсуждения проекта.
