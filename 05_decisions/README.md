# Проектные решения EventFlow

Здесь хранится журнал согласованных решений,
предложений и открытых вопросов проекта.

Каждая запись должна содержать:

- дату;
- тему;
- описание вопроса;
- рассмотренные варианты;
- принятое решение;
- статус: согласовано, предлагается или открытый вопрос.

В журнал включаются только решения, подтверждённые
в ходе обсуждения проекта.
