# История изменений EventFlow

Здесь фиксируются значимые изменения проекта:

- обновления спецификации;
- изменения архитектуры;
- новые функции;
- изменения базы данных;
- важные исправления;
- переходы между версиями.

Каждая запись содержит дату, номер версии,
описание изменений и ссылки на связанные документы.
