# База данных EventFlow

Здесь хранятся:

- актуальная структура базы данных;
- SQL-функции;
- RLS-политики;
- миграции и изменения схемы.

Все изменения базы данных должны фиксироваться
отдельными миграциями с описанием назначения,
проверок и результата выполнения.

Секреты, пароли, токены и персональные данные
в репозиторий не добавляются.
