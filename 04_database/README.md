# Database

Раздел содержит SQL-документацию, исторические снимки структуры базы данных, диагностические запросы и миграции EventFlow.

## Структура раздела

### initial/

Исторический архив первоначальных SQL-файлов EventFlow.

Содержит исходную структуру базы, тестовые данные, определения RPC-функций и диагностические запросы.

Архив используется для изучения истории разработки и сравнения версий.

### migrations/

Будущий раздел для последовательных изменений структуры базы данных.

Каждая миграция должна:

- иметь уникальный порядковый номер;
- содержать конкретное изменение;
- учитывать текущее состояние базы;
- сопровождаться описанием назначения;
- быть проверена перед применением.

## Основные правила

1. Исторические файлы из `initial/` не переписываются.
2. Изменения действующей базы оформляются отдельными миграциями.
3. Перед созданием миграции проверяется актуальная структура Supabase.
4. Применённые миграции фиксируются в документации проекта.
5. Изменения структуры базы должны отражаться в `02_architecture/`.
6. Изменения, затрагивающие безопасность, дополнительно проверяются через аудит RLS и прав доступа.

## Важно

Архив `initial/` не является актуальным снимком базы данных.

Источником фактического состояния базы на момент разработки остаётся Supabase. Документация должна обновляться после согласованных и проверенных изменений.
