# Initial Database Archive

Исторический архив исходных SQL-файлов EventFlow.

## Назначение

Папка содержит SQL-скрипты, диагностические запросы и тесты, использовавшиеся на начальном этапе разработки EventFlow.

Файлы сохранены для:

- восстановления истории разработки;
- изучения первоначальной структуры базы;
- повторения диагностических проверок;
- сравнения первоначального состояния с последующими версиями.

## Состав архива

| Файл | Назначение |
|---|---|
| `01_database_schema.sql` | Первоначальная структура таблиц |
| `02_seed_data.sql` | Первоначальные тестовые данные |
| `03_get_invitation.sql` | Исходное определение функции получения приглашения |
| `04_submit_rsvp.sql` | Исходное определение функции сохранения RSVP |
| `05_rpc_permissions_check.sql` | Проверка прав выполнения RPC-функций |
| `06_table_permissions_check.sql` | Проверка прямых прав на таблицы |
| `07_rls_policies_check.sql` | Проверка RLS и политик |
| `08_indexes_check.sql` | Проверка индексов |
| `09_constraints_check.sql` | Проверка ограничений |
| `10_functions_check.sql` | Инвентаризация функций |
| `11_rsvp_tests.sql` | Тестовые запросы RSVP |

## Важные предупреждения

1. Архив не является актуальным снимком базы данных.
2. Исторические SQL-скрипты создания структуры и тестовых данных нельзя запускать повторно без предварительной проверки.
3. Диагностические запросы не изменяют данные, но показывают состояние базы на момент их выполнения.
4. Определения функций отражают сохранённые версии, полученные из Supabase.
5. Перед созданием миграций необходимо сверять архив с фактической структурой базы.

## Принцип ведения архива

Исторические файлы не переписываются при изменении продукта.

Новые изменения оформляются отдельными миграциями и документируются в соответствующих разделах проекта.
