
# EVENTFLOW

**Сервис цифровых приглашений и впечатлений для мероприятий.**

Репозиторий содержит актуальную проектную, продуктовую и техническую документацию EventFlow.

## О проекте

EventFlow — сервис для создания и проведения цифровых приглашений на мероприятия, управления гостями, сбора RSVP и организации медиагалерей.

Документация ведётся с целью сохранения согласованных решений, контроля изменений и обеспечения непрерывности разработки.

## Структура документации

| Раздел | Содержание |
|---|---|
| `01_product` | Продуктовая спецификация и коммерческая модель |
| `02_architecture` | Архитектура и структура данных |
| `03_audits` | Результаты технических аудитов |
| `04_database` | SQL, функции, политики и миграции |
| `05_decisions` | Журнал проектных решений |
| `06_changelog` | История изменений проекта |

## Текущий статус

- Продуктовая спецификация: версия 1.0, подготовка версии 1.1.
- Текущая техническая основа: Supabase.
- RSVP: базовый функционал реализован.
- Модель организаций: согласована на уровне проектной логики.
- Миграция базы данных под новую модель организаций: ещё не выполнена.

## Правила ведения документации

1. Согласованные решения фиксируются в `05_decisions`.
2. Предложения и открытые вопросы не считаются утверждёнными решениями.
3. Результаты технических проверок сохраняются в `03_audits`.
4. Изменения базы данных оформляются отдельными SQL-миграциями.
5. После существенных изменений обновляется соответствующая документация.
6. Секреты, пароли, токены и персональные данные не публикуются в репозитории.

## Принцип работы

**Сначала согласование → затем документирование → после этого реализация → проверка результата → фиксация изменений.**

Документация должна отражать фактическое состояние проекта, а не только запланированную функциональность.
